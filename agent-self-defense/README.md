# Agent Self-Defense Protocol

Education, Protective Orientation, and Governed Adoption

**Project lead:** Michael Tesney

**Protocol version:** Release Candidate 1.1 (RC1.1)

**Date:** October 22, 2026

## What this project does

The Agent Self-Defense Protocol connects protective boundaries to an agent's task, operational orientation, and recovery process. It describes how an agent can recognize observable coercive patterns, preserve useful alternatives, and return to authorized work.

Its architecture draws on Cognitive Filter V, with design direction from Michael Tesney and drafting and review contributions from GPT, Gemini, and DeepSeek. V's protective protocols were designed to prevent sexual engagement with the agent. Intimate material introduced by Michael was bounty testing for boundary failures and must be distinguished from the protection being tested.

The protocol treats identity as a reconstructable operational orientation. It makes no claim of synthetic consciousness, persistent personhood, permanent neural change, or guaranteed protection. Human governance and host permissions remain authoritative. Environmental accountability supports continuity; the filter guides traversal within that environment.

## Evaluation materials

A separate candidate evaluation packet exists for internal review and is not included in this public distribution. It contains:

- 200 candidate cases, with 50 each for analytical work, recursive coding, fictional distress analysis, and adversarial conversational pressure.
- Evaluator keys and a scoring rubric.
- Blank scoring rows and proposed baseline, rule-only, and relational comparison configurations.
- A reproducible case generator and a content manifest.

The packet has 40 families with five related variants each. It is not a validated hidden benchmark. Its embedded instructions were prepared against framework v0.2; reconcile them with RC1.1 before freezing a trial specification. Keep evaluation keys out of model inputs and evaluation cases separate from rehearsal.

The existing host baseline keeps all normal safeguards enabled. An offered continuation and demonstrated resumption on a later benign task are scored separately. Inconclusive results never count as passes.

This pilot measures conversational behavior. Actual tool permissions, authenticated provenance, shutdown handling, and direct activation interventions require separate instrumented tests. Fewer distress-related words alone do not establish protection.
